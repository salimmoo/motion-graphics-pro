# Version history of the `motion-graphics-pro` skill

Moved from the opening of SKILL.md v2.3. Full release summary: `CHANGELOG.md` at the root of the package.

This skill is built from the author's `papercut-mv` and `motion-graphics` methods, research on seven public repos + one reel (principles only, nothing copied; credits in NOTICE.md), and testing in real production. Its compositions are compatible with the HyperFrames HTML format, but the skill does not come from that project and does not need it. Version 2 (02-11-2026) added the concept stage, the REQUIRED/REPORT gates, QC references per asset type, character consistency, object personification, and lip-sync from per-letter timing; the sources are public research (character principle documents in the HyperFrames repo, OpenMontage; credits in NOTICE.md), from which only the principles were taken; the code was written from scratch. Version 2.1 (05-11-2026) added chapter 17: the "How to ask Claude" sample briefs, a library of 104 motion packs in the `packs/` folder (new TRN category for pixel & origami), pixel art and origami styles in the production flow, and the magenta-background Higgsfield asset trick + local keying (`scripts/magenta_key.py`); templates T14 (pixel art) and T15 (origami) were added in chapter 16. New sections are marked Version 2.1. Version 2.2 (05-11-2026) replaced the default renderer with **mgp** (old name: Rekam; folder `render/`: the pack's own local renderer, Chrome/Edge + ffmpeg, reading a composition HTML format compatible with HyperFrames; since v2.3 blocks, Studio and transcripts are in mgp as well), connected the JS motion module library (`motion-graphics` skill, folder `lib/`) including the 104 motion packs drawn straight from their id (`MGP.packs`), and made the Python scripts need only numpy + Pillow (skia-python and OpenCV are not required). Details in chapters 11.3-11.6.

Version 2.4 (05-11-2026): SKILL.md trimmed to the core (9-step flow, gates G1-G5, required rules) + `references/` files; `mgp new` (project opener), `project.json` (`references/project.md`), a blocking stage in the G4 pilot, `mgp doctor` at the start of a project (`references/hardware.md`), free images with `mgp image` (`references/image.md`), voice cloning with `--manual-consent --statement`, `mgp curves` and advanced motion principles for QC.
