## 14. Mistakes that were rejected before

| Rejected | Replacement |
|---|---|
| Vector paper drawn in code (childish) | Real paper kit pieces |
| One full AI plate + overlay (not a collage) | A 21:9 kit assembled piece by piece, or a keyframe split into layers (chapter 15) |
| Split-pin puppet rig, joints/pins visible | Sequence motion from a sheet |
| Props with no purpose or floating | Removed, or attached with context |
| Sun badge drawn in code | Sun/disc from the kit + glow in code |
| Map drawn by AI or viewBox stretched | Natural Earth + real coordinates (chapter 9) |
| Mouth sticker in the wrong place | Head anchor per frame + contact per frame |
| Prompt "lo-fi anime background painting" (flat) | Real-paper STYLE block (4.3) |
| Placeholder effect sent as if final | PLACEHOLDER label in the frame + delivery note |
| Layer-split sheet that redraws (oversized layers, pose changed) | Prompt "COPY, do not redraw" + KEEP/ERASE percentages + required matching (15.1) |
